# Welcome to gobhi

**gobhi** is a simple framework for building web applications.

This repository contains the source code for the gobhi framework. It is structured as a **monorepo** and managed using **pnpm**.

* The `packages` directory contains the main framework package, **Gobhi**.
* The `apps` directory contains demo projects used for testing, experimentation, and implementing the framework.

Together, these projects provide a workspace for developing, testing, and improving the gobhi framework.
